# Materiales de origen

Esta carpeta reúne los archivos de trabajo que se usaron para preparar las materias,
pero que no forman parte de las webs publicadas.

- `chats/`: exportaciones y conversiones de conversaciones.
- `sistema-computacion/`: texto e imágenes extraídos para esa materia.
- `materias/`: documentos, imágenes y texto fuente de cada curso.

Está excluida de Git y del despliegue para mantener el repositorio y el sitio limpios.
